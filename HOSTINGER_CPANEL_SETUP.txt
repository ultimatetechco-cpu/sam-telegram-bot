========================================================================
🚀 HOSTINGER CPANEL / SUBDOMAIN 1-CLICK DEPLOYMENT GUIDE
========================================================================

नमस्ते! यह प्रोजेक्ट Hostinger cPanel के सबडोमेन पर चलने के लिए पूरी तरह
तैयार है। नीचे दिए गए 3 आसान स्टेप्स फॉलो करें:

------------------------------------------------------------------------
📌 STEP 1: सबडोमेन के फ़ोल्डर में ZIP एक्सट्रैक्ट करें (File Manager)
------------------------------------------------------------------------
1. अपने Hostinger cPanel में लॉगिन करें और "File Manager" खोलें।
2. जब आप सबडोमेन बनाते हैं (जैसे: bot.yourdomain.com या auto.yourdomain.com),
   तो cPanel उसके लिए एक फ़ोल्डर बनाता है:
   या तो: /home/username/public_html/bot
   या:    /home/username/bot.yourdomain.com
3. इस फ़ोल्डर के अंदर "hostinger_subdomain_ready.zip" अपलोड करें।
4. फ़ाइल पर राइट-क्लिक करके "Extract" कर दें।

------------------------------------------------------------------------
📌 STEP 2: cPanel में Python App सेटअप करें ("Setup Python App")
------------------------------------------------------------------------
1. cPanel के होम पेज पर जाएं और "Setup Python App" सर्च करें।
2. "Create Application" (नीला बटन) पर क्लिक करें।
3. ये 5 सेटिंग्स भरें:
   • Python version:         3.10, 3.11, या 3.12 चुनें
   • Application root:       अपने सबडोमेन वाले फ़ोल्डर का नाम
                             (जैसे: bot.yourdomain.com या public_html/bot)
   • Application URL:        अपना सबडोमेन चुनें (जैसे: bot.yourdomain.com)
   • Application startup file: passenger_wsgi.py
   • Application Entry point:  application
4. ऊपर दाएँ कोने में "CREATE" बटन पर क्लिक करें।

------------------------------------------------------------------------
📌 STEP 3: डिपेंडेंसीज (Packages) इनस्टॉल करें और रीस्टार्ट करें
------------------------------------------------------------------------
1. अप्लीकेशन क्रिएट होते ही स्क्रीन पर ऊपर एक एक्टिवेशन कमांड दिखेगी:
   (उदा: source /home/username/virtualenv/bot/3.11/bin/activate && cd ...)
2. cPanel का "Terminal" खोलें, वह कमांड पेस्ट करके Enter दबाएं।
3. अब यह कमांड चलाएं:
   pip install -r requirements.txt
4. वापस "Setup Python App" पेज पर जाएं और ऊपर "RESTART" बटन दबाएं।

------------------------------------------------------------------------
